## ?? Sécurité avec OIDC

### Avantages de l'authentification OIDC :

? **Pas de secrets stockés** : Pas de credentials Azure dans GitHub  
? **Authentification fédérée** : Trust entre GitHub et Azure  
? **Tokens temporaires** : Validité limitée  
? **Rotation automatique** : Pas de gestion manuelle  
? **Audit trail** : Traçabilité complète

## ?? Configuration Requise

### Secrets GitHub (4 secrets)

| Secret Name | Description | Obtention |
|-------------|-------------|-----------|
| `AZURE_CLIENT_ID` | Client ID du Service Principal | `az ad app create` |
| `AZURE_TENANT_ID` | Tenant ID Azure | `az account show --query tenantId` |
| `AZURE_SUBSCRIPTION_ID` | Subscription ID | `az account show --query id` |
| `POSTGRESQL_CONNECTION_STRING` | Connection string PostgreSQL | Construire manuellement |

### Permissions Azure

Le Service Principal a besoin du rôle **Contributor** sur le Resource Group :

```powershell
az role assignment create `
  --assignee <CLIENT_ID> `
  --role Contributor `
  --scope "/subscriptions/<SUBSCRIPTION_ID>/resourceGroups/smartoffice-prod-rg"
```

## ?? Dépannage

### Problème : "Failed to authenticate with Azure"

**Solution** :
```powershell
# Vérifier les Federated Credentials
az ad app federated-credential list --id <CLIENT_ID>

# Recréer si nécessaire
az ad app federated-credential create --id <CLIENT_ID> --parameters '...'
```

### Problème : "Health check failed"

**Solution** :
```powershell
# Voir les logs Azure
az webapp log tail --name smartoffice-prod-api --resource-group smartoffice-prod-rg

# Redémarrer l'app
az webapp restart --name smartoffice-prod-api --resource-group smartoffice-prod-rg
```

### Problème : "Migrations failed"

**Solution** :
```powershell
# Tester la connection string
psql "<CONNECTION_STRING>"

# Vérifier le firewall PostgreSQL
az postgres flexible-server firewall-rule list `
  --name smartoffice-prod-postgres `
  --resource-group smartoffice-prod-rg
```
