# ?? Backend SmartOffice - Uniforme avec Firmware ESP32

## ?? Vue d'ensemble

Ce document décrit l'architecture **complète et uniforme** du backend SmartOffice qui expose **TOUTES** les fonctionnalités du firmware ESP32 via Azure IoT Hub.

## ?? Fonctionnalités Firmware vs Backend

### ? Tableau de Correspondance

| Fonctionnalité Firmware | Backend API | Modèle DB | Service | Contrôleur |
|--------------------------|-------------|-----------|---------|------------|
| **Métriques Système** (RSSI, Heap, Uptime) | ? | DeviceMetrics | DeviceStatusService | DeviceStatusController |
| **Événements RFID** (scans, accès) | ? | RfidEvent | DeviceStatusService | DeviceStatusController |
| **Alarme Fumée** (détection, durée) | ? | SmokeAlarmEvent | DeviceStatusService | DeviceStatusController |
| **Périphériques GPIO** (relais, capteurs) | ? | DevicePeripheral | DevicePeripheralService | DevicesController |
| **Télémétrie** (valeurs capteurs) | ? | Telemetrie | TelemetrieService | TelemetriesController |
| **Logs Firmware** (erreurs, warnings) | ? | DeviceLog | DeviceLogService | DeviceLogsController |
| **Méthodes Directes** (commandes) | ? | N/A | IotHubService | IoTHubController |
| **Device Twin** (config, état) | ? | N/A | IotHubService | DevicesController |
| **Energy Metering** (consommation) | ? | DevicePeripheral | DevicePeripheralService | DevicesController |

## ?? Endpoints API Complets

### 1?? Statut Complet Device
```http
GET /api/DeviceStatus/{iotDeviceId}/full-status
```
**Retourne:**
- Métriques système (RSSI, Heap, Uptime)
- Dernier événement RFID
- Alarme active (si existante)
- État de tous les périphériques GPIO
- Statut de connexion IoT Hub

### 2?? Métriques Système
```http
POST /api/DeviceStatus/{iotDeviceId}/metrics
GET  /api/DeviceStatus/{iotDeviceId}/metrics?startDate=...&endDate=...
GET  /api/DeviceStatus/{iotDeviceId}/metrics/latest
```

### 3?? Événements RFID
```http
POST /api/DeviceStatus/{iotDeviceId}/rfid-events
GET  /api/DeviceStatus/{iotDeviceId}/rfid-events?startDate=...&endDate=...
GET  /api/DeviceStatus/rfid-events/by-card/{cardUid}
GET  /api/DeviceStatus/rfid-events/denied-access
```

### 4?? Alarmes Fumée
```http
POST /api/DeviceStatus/{iotDeviceId}/smoke-alarms
POST /api/DeviceStatus/{iotDeviceId}/smoke-alarms/deactivate
GET  /api/DeviceStatus/{iotDeviceId}/smoke-alarms/active
GET  /api/DeviceStatus/smoke-alarms/all-active
```

### 5?? Périphériques GPIO
```http
GET  /api/Devices/{iotDeviceId}/peripherals
GET  /api/Devices/{iotDeviceId}/peripherals/{name}
POST /api/Devices/{iotDeviceId}/peripherals
PUT  /api/Devices/{iotDeviceId}/peripherals
DELETE /api/Devices/{iotDeviceId}/peripherals/{name}
POST /api/Devices/{iotDeviceId}/peripherals/{name}/commands/{command}
GET  /api/Devices/{iotDeviceId}/peripherals/energy
```

### 6?? Télémétrie
```http
GET /api/telemetrie/peripherique?peripheriqueId=...
GET /api/telemetrie/history?startDate=...&endDate=...
POST /api/telemetrie/add
```

### 7?? Logs Firmware
```http
GET /api/DeviceLogs/{deviceId}
GET /api/DeviceLogs/{deviceId}/level/{level}
GET /api/DeviceLogs/search
```

### 8?? IoT Hub Management
```http
GET  /api/IoTHub/devices
POST /api/IoTHub/devices/sync
POST /api/IoTHub/device/{deviceId}/method/{methodName}
GET  /api/IoTHub/device/{deviceId}/twin
POST /api/IoTHub/device/{deviceId}/peripherals/sync
```

## ?? Flux de Données

### ?? Firmware ? Backend (Télémétrie)

```
ESP32 Firmware
  ?
  ?? sendTelemetry()        ? Azure IoT Hub ? TelemetrieIngestionWorker
  ?                                          ? PostgreSQL (Telemetrie)
  ?
  ?? sendLog()              ? Azure IoT Hub ? LogIngestionWorker
  ?                                          ? PostgreSQL (DeviceLog)
  ?
  ?? reportMetrics()        ? Device Twin Reported Properties
  ?                            (Backend lit via GetDeviceTwinAsync)
  ?
  ?? reportPeripherals()    ? Device Twin Reported Properties
                               (Backend lit via GetDeviceTwinAsync)
```

### ?? Backend ? Firmware (Commandes)

```
Backend API
  ?
  ?? InvokeDeviceMethodAsync()     ? Azure IoT Hub ? ESP32 handleDirectMethod()
  ?
  ?? UpdateDesiredPropertiesAsync() ? Device Twin Desired
                                      ? ESP32 handleTwinDesiredBody()
```

## ?? Notifications SignalR

### Événements Temps Réel

```javascript
// Connexion SignalR
const connection = new signalR.HubConnectionBuilder()
  .withUrl("https://localhost:7152/notificationhub", {
    accessTokenFactory: () => authToken
  })
  .build();

// Écouter les notifications
connection.on("ReceiveNotification", (notification) => {
  console.log(`${notification.title}: ${notification.message}`);
});

// Exemple: Accès RFID refusé
// "Accès RFID Refusé: Tentative d'accès refusée avec carte 12345678"

// Exemple: Alarme fumée
// "?? ALARME FUMÉE: Alarme fumée détectée sur mon-esp32 à 11:00:00"
```

## ??? Configuration et Déploiement

### 1. Prérequis
- .NET 9 SDK
- PostgreSQL 16+
- Azure IoT Hub
- Compte Azure (pour IoT Hub)

### 2. Configuration
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=smartoffice;Username=...;Password=..."
  },
  "IotHubConnectionString": "HostName=brainoffice.azure-devices.net;SharedAccessKeyName=...",
  "JwtSettings": {
    "Secret": "...",
    "Issuer": "SmartOfficeAPI",
    "Audience": "SmartOfficeClients"
  }
}
```

### 3. Migration Base de Données
```bash
cd SmartOfficeAPP
dotnet ef database update
```

### 4. Démarrage
```bash
dotnet run
```
