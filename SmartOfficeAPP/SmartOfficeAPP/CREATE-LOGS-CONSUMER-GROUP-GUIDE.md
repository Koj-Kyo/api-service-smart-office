# ?? Guide de création du Consumer Group "logs" - Azure IoT Hub

## ?? Vue d'ensemble

Ce guide vous montre **étape par étape** comment créer le consumer group **"logs"** dans votre IoT Hub Azure pour activer le `LogIngestionWorker`.

---

## ?? Pourquoi créer un consumer group "logs" ?

### Architecture des Consumer Groups

```
??????????????????????????????????????????????????????????
?          AZURE IOT HUB EVENT HUB (Built-in)            ?
??????????????????????????????????????????????????????????
?                                                        ?
?  ????????????????????      ????????????????????      ?
?  ?  Consumer Group  ?      ?  Consumer Group  ?      ?
?  ?    $Default      ?      ?      logs        ?      ?
?  ?  (Télémétrie)    ?      ?   (Logs ESP32)   ?      ?
?  ????????????????????      ????????????????????      ?
?         ?                           ?                 ?
?         ?                           ?                 ?
?  ??????????????????        ??????????????????        ?
?  ? Telemetrie     ?        ? LogIngestion   ?        ?
?  ? IngestionWorker?        ? Worker         ?        ?
?  ??????????????????        ??????????????????        ?
?                                                        ?
??????????????????????????????????????????????????????????
```

**Avantages :**
- ? **Séparation des responsabilités** : télémétrie et logs dans des workers différents
- ? **Checkpoints indépendants** : chaque worker garde sa position de lecture
- ? **Pas de conflit** : plusieurs consumers peuvent lire en parallèle
- ? **Meilleure observabilité** : logs structurés séparés des métriques

## ?? Méthode 2 : Via Azure CLI (Avancé)

### Prérequis

```powershell
# Vérifier que Azure CLI est installé
az --version

# Se connecter à Azure
az login
```

### Commande pour créer le consumer group

```powershell
# Variables (remplacez par vos valeurs)
$IOT_HUB_NAME = "brainoffice"
$RESOURCE_GROUP = "smartoffice-prod-rg"
$CONSUMER_GROUP_NAME = "logs"

# Créer le consumer group
az iot hub consumer-group create `
  --hub-name $IOT_HUB_NAME `
  --resource-group $RESOURCE_GROUP `
  --name $CONSUMER_GROUP_NAME

# Vérifier la création
az iot hub consumer-group list `
  --hub-name $IOT_HUB_NAME `
  --resource-group $RESOURCE_GROUP `
  --output table
```

**Résultat attendu :**

```
Name       ResourceGroup         IotHubName
---------  --------------------  ------------
$Default   smartoffice-prod-rg   brainoffice
logs       smartoffice-prod-rg   brainoffice
```

? **Consumer group créé !**

## ?? Méthode 3 : Via Script PowerShell Automatisé

Créez un fichier `create-logs-consumer-group.ps1` :

```powershell
# create-logs-consumer-group.ps1
# Script automatisé pour créer le consumer group "logs"

param(
    [Parameter(Mandatory=$true)]
    [string]$IotHubName,
    
    [Parameter(Mandatory=$true)]
    [string]$ResourceGroup,
    
    [Parameter(Mandatory=$false)]
    [string]$ConsumerGroupName = "logs"
)

Write-Host "?? Création du consumer group '$ConsumerGroupName'..." -ForegroundColor Cyan

# Vérifier si Azure CLI est installé
if (-not (Get-Command az -ErrorAction SilentlyContinue)) {
    Write-Host "? Azure CLI n'est pas installé. Installez-le d'abord :" -ForegroundColor Red
    Write-Host "   https://aka.ms/installazurecliwindows" -ForegroundColor Yellow
    exit 1
}

# Vérifier si l'utilisateur est connecté
Write-Host "?? Vérification de la connexion Azure..." -ForegroundColor Gray
$account = az account show 2>$null
if (-not $account) {
    Write-Host "?? Vous n'êtes pas connecté à Azure. Connexion..." -ForegroundColor Yellow
    az login
    if ($LASTEXITCODE -ne 0) {
        Write-Host "? Échec de la connexion Azure" -ForegroundColor Red
        exit 1
    }
}

# Vérifier si l'IoT Hub existe
Write-Host "?? Vérification de l'IoT Hub '$IotHubName'..." -ForegroundColor Gray
$hubExists = az iot hub show --name $IotHubName --resource-group $ResourceGroup 2>$null
if (-not $hubExists) {
    Write-Host "? IoT Hub '$IotHubName' introuvable dans le resource group '$ResourceGroup'" -ForegroundColor Red
    exit 1
}

# Vérifier si le consumer group existe déjà
Write-Host "?? Vérification si le consumer group '$ConsumerGroupName' existe..." -ForegroundColor Gray
$existingGroups = az iot hub consumer-group list --hub-name $IotHubName --resource-group $ResourceGroup --query "[].name" -o tsv
if ($existingGroups -contains $ConsumerGroupName) {
    Write-Host "? Le consumer group '$ConsumerGroupName' existe déjà" -ForegroundColor Green
    exit 0
}

# Créer le consumer group
Write-Host "?? Création du consumer group '$ConsumerGroupName'..." -ForegroundColor Yellow
az iot hub consumer-group create `
    --hub-name $IotHubName `
    --resource-group $ResourceGroup `
    --name $ConsumerGroupName

if ($LASTEXITCODE -eq 0) {
    Write-Host "? Consumer group '$ConsumerGroupName' créé avec succès !" -ForegroundColor Green
    Write-Host ""
    Write-Host "?? Liste des consumer groups actuels :" -ForegroundColor Cyan
    az iot hub consumer-group list `
        --hub-name $IotHubName `
        --resource-group $ResourceGroup `
        --output table
} else {
    Write-Host "? Échec de la création du consumer group" -ForegroundColor Red
    exit 1
}

Write-Host ""
Write-Host "?? Configuration terminée !" -ForegroundColor Green
Write-Host ""
Write-Host "?? Prochaines étapes :" -ForegroundColor Cyan
Write-Host "   1. Vérifiez que 'LogsEnabled: true' dans appsettings.json" -ForegroundColor White
Write-Host "   2. Redémarrez le backend : dotnet run" -ForegroundColor White
Write-Host "   3. Vérifiez les logs : LogIngestionWorker démarré avec succès" -ForegroundColor White
Write-Host ""
```

**Utilisation :**

```powershell
.\create-logs-consumer-group.ps1 -IotHubName "brainoffice" -ResourceGroup "smartoffice-prod-rg"
```

## ?? Modification du firmware ESP32 (pour envoyer des logs)

### Exemple de code ESP32

```cpp
// Envoyer un log depuis l'ESP32
void sendLog(const char* level, const char* source, const char* message) {
  StaticJsonDocument<256> doc;
  
  doc["level"] = level;       // "info", "warn", "error"
  doc["source"] = source;     // "wifi", "iot", "peripheral"
  doc["message"] = message;
  doc["timestamp"] = getISOTimestamp();
  doc["peripheral"] = nullptr; // Optionnel
  
  String payload;
  serializeJson(doc, payload);
  
  // Créer un message avec property "type" = "log"
  Message msg(payload.c_str());
  msg.addProperty("type", "log");  // ? IMPORTANT
  
  deviceClient.sendEventAsync(msg);
  
  Serial.printf("[LOG] Sent: %s - %s - %s\n", level, source, message);
}

// Exemples d'utilisation
void setup() {
  sendLog("info", "wifi", "WiFi connected successfully");
  sendLog("info", "iot", "Connected to Azure IoT Hub");
}

void loop() {
  if (smokeDetected) {
    sendLog("error", "smoke_sensor", "Smoke detected! Alert triggered");
  }
  
  if (commandExecuted) {
    sendLog("info", "command", "LED turned ON successfully");
  }
}
```

### Différence entre Télémétrie et Logs

| Type | Property `type` | Consumer Group | Données |
|------|----------------|----------------|---------|
| **Télémétrie** | `"telemetry"` (optionnel) | `$Default` | Métriques, états, consommation |
| **Logs** | `"log"` (obligatoire) | `logs` | Logs applicatifs, événements |

## ?? Dépannage

### Erreur : "Consumer group already exists"

**Cause** : Le consumer group existe déjà

**Solution** : Pas de problème, continuez !

### Erreur : "The messaging entity '...|logs' could not be found"

**Cause** : Le consumer group n'est pas créé ou mal nommé

**Solution** :
1. Vérifiez l'orthographe : `logs` (en minuscules)
2. Vérifiez dans le Portail Azure
3. Recréez le consumer group

### Erreur : "BlobContainer 'iothub-logs-checkpoints' not found"

**Cause** : Le container Blob n'existe pas

**Solution** :
```powershell
# Créer le container
az storage container create \
  --name iothub-logs-checkpoints \
  --account-name VOTRE_STORAGE_ACCOUNT
```
